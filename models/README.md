# Model Artifacts

This directory is reserved for model metadata and approved model artifacts.

## Safety and handling

- Do not commit credentials, private datasets, or customer data.
- Record the origin, version, license, and checksum for every added artifact.
- Review model files before loading them; do not load untrusted serialized objects.
- Keep large binary artifacts out of Git unless the maintainers have approved a storage method.
- Examples in this repository use synthetic data and do not require model downloads.

No model artifact is required to run the bundled offline examples.
