# External References

The following resources are recommended for additional learning, research, threat intelligence, security validation, and technical reference.

## 1. Core References

- [MITRE ATT&CK](https://attack.mitre.org/) — Knowledge base of adversary tactics and techniques for threat modeling and ATT&CK mapping.
- [MITRE Attack Flow](https://center-for-threat-informed-defense.github.io/attack-flow/overview/) — Represents sequences and relationships between adversary behaviors to support attack-flow analysis.
- [National Vulnerability Database (NVD)](https://nvd.nist.gov/) — Vulnerability records, security metadata, and CVE-related data.
- [FIRST Exploit Prediction Scoring System (EPSS)](https://www.first.org/epss/) — Estimates the probability that a vulnerability will be exploited in the next 30 days.

## 2. Simulation & Security Validation

- [CVE Program](https://www.cve.org/) — Standardized identifiers for publicly disclosed cybersecurity vulnerabilities.
- [CISA Known Exploited Vulnerabilities (KEV) Catalog](https://www.cisa.gov/known-exploited-vulnerabilities-catalog) — Vulnerabilities known to have been exploited in the wild.
- [MITRE CALDERA](https://caldera.readthedocs.io/stable/) — Automated adversary emulation based on MITRE ATT&CK.
- [Atomic Red Team](https://www.atomicredteam.io/) — Security tests mapped to adversary techniques for validating defensive controls.

## 3. Supporting Security & Technical References

- [MITRE D3FEND](https://d3fend.mitre.org/) — Defensive cybersecurity techniques and countermeasures.
- [CIS Benchmarks](https://www.cisecurity.org/cis-benchmarks) — Secure configuration recommendations for systems and applications.
- [NetworkX Documentation](https://networkx.org/documentation/stable/) — Graph structures and algorithms for attack-graph construction and analysis.
- [scikit-learn Documentation](https://scikit-learn.org/stable/) — Machine-learning algorithms, preprocessing, model evaluation, and predictive analysis.
