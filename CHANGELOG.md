# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and this project adheres to [Semantic Versioning](https://semver.org/).

## [v0.0.1] - 2026-09-05

### Added

- Initial open-source pre-release of AAPP-MART Community Edition.
- Initial architecture and core module documentation.
- Quickstart and usage documentation.
- Ethical-use, development, and testing documentation.

## [v0.0.2] - 2026-11-17

### Added

- Added core execution contracts and shared interfaces for AAPP, MART, and ENGINE.
- Added unified execution request and response structures.
- Added prediction and simulation contracts.
- Added centralized execution pipeline and orchestration.
- Added runtime lifecycle management.
- Added deterministic execution support with seed handling.
- Added standardized execution results and error handling.
- Added AAPP-to-ENGINE integration.
- Added MART-to-ENGINE integration.
- Added lifecycle event coordination.
- Added AAPP risk scoring.
