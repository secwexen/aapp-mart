# External References

The following resources are recommended for additional learning, research, threat intelligence, security validation, and technical reference.

## 1. Core References

- [MITRE ATT&CK](https://attack.mitre.org/) — Knowledge base of adversary tactics and techniques for threat modeling and ATT&CK mapping.
- [MITRE Attack Flow](https://center-for-threat-informed-defense.github.io/attack-flow/overview/) — Represents sequences and relationships between adversary behaviors to support attack-flow analysis.
- [National Vulnerability Database (NVD)](https://nvd.nist.gov/) — Vulnerability records, security metadata, and CVE-related data.
- [CVE Program](https://www.cve.org/About/Overview) — Standardized identifiers and records for publicly disclosed cybersecurity vulnerabilities.
- [CISA Known Exploited Vulnerabilities (KEV) Catalog](https://www.cisa.gov/known-exploited-vulnerabilities-catalog) — Identifies vulnerabilities known to have been exploited in the wild.
- [FIRST Exploit Prediction Scoring System (EPSS)](https://www.first.org/epss/) — Estimates the probability that a vulnerability will be exploited in the next 30 days.
- [MITRE CALDERA](https://caldera.readthedocs.io/stable/) — Automated adversary-emulation platform based on MITRE ATT&CK.

## 2. Supporting Security References

- [Atomic Red Team](https://www.atomicredteam.io/) — Library of focused security tests mapped to adversary techniques.
- [MITRE D3FEND](https://d3fend.mitre.org/) — Knowledge graph of defensive cybersecurity techniques and countermeasures.

## 3. Technical Reference

- [NetworkX Documentation](https://networkx.org/documentation/stable/) — Graph construction, analysis, and algorithms.
